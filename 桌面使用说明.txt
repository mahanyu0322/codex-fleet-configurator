Codex 舰队配置器

支持 Windows 和 macOS，无需安装 Python。
Windows：解压 ZIP 后打开 Codex Fleet Configurator.exe。
macOS：下载匹配 Apple Silicon / Intel 的 ZIP，解压后把 Codex Fleet Configurator.app 放入“应用程序”并打开。
初版没有 Windows 代码签名或 Apple Developer ID 公证，首次启动可能触发系统验证提示。不要关闭系统安全保护。

1. 选择“全局默认”或“指定项目”。
2. 勾选“启用舰队模式”就是舰队模式；取消勾选就是非舰队模式，由主控独立完成任务，关闭子 Agent 工具。
3. 为三个子 Agent 职责模板分别选择模型、推理强度和提供方。主控完全由 Codex 当前任务界面选择。
4. 可使用“全部设为 Luna / 极高”预设，再逐行自行调整。预设不会改变总开关或并发数。
5. 检查变更预览后，点击“保存并应用”；开关与其他参数一并保存，程序会自动备份。仅切换开关还没有保存。
6. 打开 Codex 新任务使用设置，必要时重启 Codex。现有任务及正在运行的子 Agent 不会被工具强制切换或停止。
7. 需要撤销时，在“备份恢复”选中备份后恢复，总开关也会恢复。

关闭舰队模式后，模型、推理等级、提供方、并发数继续保存；下次打开开关可直接复用。关闭时也允许提前调整参数。
开关显示所选配置文件的值；项目配置、选定配置方案、管理员约束可能改变实际生效结果。没有显式开关的文件按 Codex 默认启用状态显示，启动时不会自动保存。

极高 = xhigh；超高 = max；Ultra = ultra。
可手动输入自定义模型 ID，但首次输入后需要明确选择推理强度；服务端是否支持由对应提供方决定。
提供方应选择已配置且支持所选模型的来源；程序不会创建 API 密钥或调用模型服务。
默认并发 8 个子 Agent（取自官方示例，不是官方固定上限），不包含主控。
可直接输入 4、16 等其他正整数；工具不再硬限 3 或 8，仅校验正整数和配置文件整数表示范围。
三行是职责模板，模板可以重复创建实例；并发数不会增加配置行，也不会自动启动子 Agent。
例如设为 8，可以按需并发最多 8 个子 Agent；新增实例可复用已有模板处理独立任务。
读取已有配置时保留原并发值；点击 Luna 模型预设也不会重置并发数。
实际并发以 Codex 运行环境为准；已有任务可能保留旧上限，请新建任务，必要时重启 Codex。

程序启动时仅仅读取设置，不会自动保存，也不会重启 Codex。
保存期间请避免同时用其他编辑器修改同一配置。
保存和恢复均保留主控当前设置，旧版备份中的主控设置也不会恢复。
备份保存在对应配置目录的 fleet-config-backups 内；子 Agent 字段或角色/规则文件有后续修改时，程序会拒绝覆盖冲突项。
